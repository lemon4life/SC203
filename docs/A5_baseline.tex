\begin{abstract}
This report establishes our standardized, reproducible baseline for real-world $4\times$ image super-resolution using DoSSR (Diffusion-based Real-World Super-Resolution). We document runtime compatibility adaptations (optional PyTorch Scaled Dot-Product Attention, FP16 precision enforcement, and prompt-wrapper isolation) alongside bit-exact equivalence verifications. Across a benchmark of 100 paired real-world images from \texttt{RealSRVal\_crop128} evaluated over 10 random seeds (42--51; 2,000 generated $512\times 512$ PNGs across default and empty prompt conditions), DoSSR achieves $\text{PSNR}_Y = 24.1610$~dB, $\text{SSIM}_Y = 0.6820$, and $\text{LPIPS} = 0.3382$ under the default prompt (and $\text{PSNR}_Y = 24.2262$~dB, $\text{SSIM}_Y = 0.6845$, $\text{LPIPS} = 0.3352$ under the empty prompt). However, quantitative text-region evaluation over 193 annotated readable word boxes reveals severe stochastic instability: the cross-seed OCR disagreement rate reaches $32.83\%$ ($34.05\%$ on the 136-box OCR-solvable subset), with an overall box error rate of $76.01\%$ ($66.32\%$ on the 136 solvable boxes). We provide explicit mathematical definitions, source traceability audits, and a systematic comparison against CCSR, PNFS, and TADiSR.
\end{abstract}

\section{Introduction and Problem Formulation}
Real-world image super-resolution ($4\times$) requires reconstructing high-frequency visual details from low-resolution observations corrupted by unknown degradations. While diffusion-based SR models synthesize perceptually sharp textures, their generative priors introduce stochastic variations across inference seeds. This seed sensitivity becomes critical in semantic scene text, where latent trajectory differences cause character morphing, insertions, and illegible restorations.

In Assignment 5, we standardize upstream DoSSR on \texttt{RealSRVal\_crop128}, audit runtime compatibility and mathematical equivalence, report 10-seed full-reference whole-image metrics, and quantify text-region errors and cross-seed disagreement across all 193 labeled boxes and the 136-box OCR-solvable subset.

\section{Baseline Model and Implementation Details}
\subsection{DoSSR Architecture and Sampling Schedule}
Our baseline is DoSSR (built on Stable Diffusion 2.1 + ControlNet). All baseline runs fix:
\begin{itemize}
    \item Super-resolution scale: $4\times$ ($128\times 128 \to 512\times 512$).
    \item Sampler: 3rd-order ODE solver, strictly 5 sampling steps, \texttt{trunc\_12} schedule ($t_1 = T/2$).
    \item Preprocessor \& color correction: RealESRNet feature encoder; wavelet color correction.
    \item Precision \& hardware: \texttt{FP16} on NVIDIA L4 (\texttt{22.5~GiB} VRAM; \texttt{7.32~GiB} allocated / \texttt{8.28~GiB} reserved at $512\times 512$, \texttt{1.92~s/image} with SDPA off).
\end{itemize}

\subsection{Runtime Compatibility and Equivalence Checks}
\begin{enumerate}
    \item \textbf{PyTorch SDPA Integration:} Optional SDPA support reduces memory on large resolutions. At $512\times 512$ on \texttt{test\_LR}, SDPA ON vs.\ OFF produces a mean absolute pixel difference of $0.0334$ (max $2.0$ on \texttt{0..255}). All official 10-seed studies keep \texttt{disable\_sdpa: true} (\texttt{SDPA OFF}) so results reflect 100\% unmodified upstream attention math.
    \item \textbf{Prompt Wrapper Isolation:} Wrapping DoSSR to test the empty prompt gives bit-exact equivalence ($\Delta = 0.0000$) when configured to upstream default (\texttt{clean, high-resolution, 8k}).
    \item \textbf{Seed Determinism:} Fixing seed 42 twice on three \texttt{test\_LR} inputs yields bit-identical PNGs ($\text{mean\_abs\_diff} = 0.0000$, $\text{max\_abs\_diff} = 0$), whereas changing seed 42 to seed 43 produces an aggregate pixel difference of $8.8237$ (max $255$).
\end{enumerate}

\section{Experimental Protocol and Metric Definitions}
\subsection{Dataset and Ground-Truth Annotation}
We evaluate on \texttt{RealSRVal\_crop128}: 100 paired PNGs (\texttt{Canon\_001}--\texttt{050}, \texttt{Nikon\_001}--\texttt{050}) mapping $128\times 128$ \texttt{test\_LR} inputs to $512\times 512$ \texttt{test\_HR} references. Human ground-truth labeling identified 25 text-positive images containing 193 readable word boxes (50 Canon, 143 Nikon).

\subsection{Mathematical Metric Formulations}
\paragraph{Whole-Image Metrics:} Implemented in \texttt{scripts/compute\_metrics.py} in \texttt{float64} on \texttt{[0, 1]} with \texttt{crop\_border=0}: $\text{PSNR} = 10\log_{10}(1.0/(\text{MSE}+10^{-8}))$ and $11\times 11$ Gaussian SSIM ($\sigma=1.5$, valid padding) on both RGB and ITU-R BT.601 luminance ($Y$), plus AlexNet LPIPS (\texttt{normalize=True}).
\paragraph{Box Error Rate ($1-\text{WCR}$):} A box prediction is marked incorrect if $\ge 1$ character differs from the normalized ground-truth transcript:
\begin{equation}
\text{Box Error Rate} = \frac{1}{B} \sum_{b=1}^B \mathbf{1}\bigl(T_{\text{pred}}(b) \ne T_{\text{gt}}(b)\bigr)
\end{equation}
\paragraph{Character Error Rate (CER):} $\text{CER} = \text{Levenshtein}(T_{\text{pred}}, T_{\text{gt}}) / \max(1, |T_{\text{gt}}|)$.
\paragraph{Cross-Seed Disagreement Rate:} For box $b$ evaluated across $K = 10$ seeds (42--51), there are $\binom{10}{2} = 45$ unordered seed pairs $(i, j)$ ($1 \le i < j \le 10$). Letting $T_i(b)$ denote the normalized RapidOCR transcript under seed $i$:
\begin{equation}
\text{Disagreement}(b) = \frac{1}{\binom{K}{2}} \sum_{1 \le i < j \le K} \mathbf{1}\bigl(T_i(b) \ne T_j(b)\bigr) = \frac{1}{45} \sum_{1 \le i < j \le 10} \mathbf{1}\bigl(T_i(b) \ne T_j(b)\bigr)
\end{equation}
The box-weighted dataset average across all 193 boxes is $\overline{\text{Disagreement}}_{\text{box}} = \frac{1}{193} \sum_{b=1}^{193} \text{Disagreement}(b) = 32.83\%$ (and $34.05\%$ across the 136-box OCR-solvable subset; image-mean averages are $31.57\%$ and $31.10\%$, respectively).

On \texttt{Canon\_001\_LR4.png} (``\texttt{eduroam}''), DoSSR fails in 10 out of 10 seeds (42--51), producing 10 distinct full OCR transcripts (whose final tokens across seeds 42--51 are \texttt{odureani}, \texttt{aduronm}, \texttt{odareum}, \texttt{oduroant}, \texttt{edureain}, \texttt{cduroniv}, \texttt{adaroam}, \texttt{odoroam}, \texttt{ddaroain}, and \texttt{aduronm}) and a mean crop pixel spread $L_1 = 19.17$.

\paragraph{Traceability Audit of Earlier Seed-42 Figures:} Earlier qualitative comparisons differed on `seed 42` for two verified reasons: (1) upstream \texttt{inference.py} calls \texttt{pl.seed\_everything(args.seed)} once per folder while \texttt{utils/file.py} traverses \texttt{os.walk()} unsorted; thus \texttt{CELL 18} loaded the 1-image study (\texttt{prompt-check-1img}, 1st RNG draw), whereas \texttt{plot\_eduroam\_10seeds.py} and \texttt{text\_eval.py} loaded the 100-image study (\texttt{seed-study-100img}, later RNG draw); (2) \texttt{data/text\_boxes\_realsr.csv} uses the tight word box ($320,38,192,46$) for OCR, whereas both figure scripts crop ($310,5,202,85$) to show the full sign with Wi-Fi arcs. We standardize all figures to read from the 100-image study directory.

\section{Conclusion and Reproducibility Guide}
While DoSSR delivers competitive whole-image LPIPS ($0.3352$--$0.3382$), it exhibits $32.83\%$ cross-seed OCR disagreement ($34.05\%$ on OCR-solvable boxes) and $66.32\%$ solvable box error rate. All baseline artifacts are reproducible via:
\begin{verbatim}
# 1. 10-Seed DoSSR Inference (SDPA OFF, FP16, 5 steps)
python src/run_dossr.py --config configs/seed_study_realsr_100img_10seed_default_prompt_sdpa_off.yaml

# 2. Whole-Image Metrics (DoSSR 10-Seed & Bicubic x4 Floor)
python scripts/compute_metrics.py --bicubic-lr-dir <TEST_LR> --gt-dir <TEST_HR> \
  --summary-csv results/metrics_bicubic_summary_by_image.csv
